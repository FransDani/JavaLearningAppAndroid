Introduction

☕

What is Java?

Java is a popular programming language! It's used to build apps, games, and websites. Created in 1995, it's now one of the most loved languages by developers worldwide! 🌍

💪

Why Learn Java?

  • 🌈 Works on any device (Windows, Mac, Android!)
  • 🎨 Object-oriented programming
  • 👥 Used by millions of developers
  • 📱 Powers all Android apps
  • 🚀 Perfect for beginners
✨
Fun Fact!

Java is named after Java coffee! ☕ The creators were sipping coffee when they thought of the name. How cool is that?

Java Syntax

👋

Your First Program!

Let's write your very first Java program - the famous "Hello World!" 🎉

public class Main {
    public static void main(String[] args) {
        System.out.println("Hello World!");
    }
}
✏️ Try it yourself!
Click "Run Code" to see the magic! ✨
🔍

Understanding the Code

📌 public class Main

This creates a class called "Main". Every Java program needs at least one class!

📌 public static void main

This is where your program starts! Think of it as the "Start" button. 🎮

📌 System.out.println()

This prints text to the screen. It's like telling your computer to say something!

💡

Remember: Java is case-sensitive! "Main" is different from "main".

Variables

🎁

What are Variables?

Variables are like labeled boxes 📦 that store information! You can put different things in them and use them later.

int age = 15;
String name = "Alex";
double height = 5.5;
boolean isHappy = true;
📝

Creating Variables

To create a variable, you need three things:

type name = value;

Example:

int score = 100;
String player = "Alex";
System.out.println(player + " scored " + score);

Click "Run Code" to see the magic! ✨
💡

Tip: Use meaningful names! "playerScore" is better than just "x".

Operators

🧮

Math Operators

Do math operations like a calculator! 🎯

int a = 10 + 5;   // Addition = 15
int b = 10 - 5;   // Subtraction = 5
int c = 10 * 5;   // Multiplication = 50
int d = 10 / 5;   // Division = 2
int e = 10 % 3;   // Remainder = 1
⚖️

Comparison Operators

Compare two things and get true or false!

5 == 5    // Equal? true ✅
5 != 3    // Not equal? true ✅
5 > 3     // Greater? true ✅
5 < 3     // Less? false ❌
5 >= 5    // Greater or equal? true ✅
🔗

Logical Operators

&& - AND (both must be true)
|| - OR (at least one true)
!  - NOT (opposite)
✏️ Try it yourself!
Click "Run Code" to see the magic! ✨
💡

Important: Use == to compare, use = to assign!

Conditions

🤔

Make Decisions!

Use if-else to make your program smart! It can decide what to do! 🧠

int score = 85;

if (score >= 90) {
    System.out.println("A grade! 🌟");
} else if (score >= 80) {
    System.out.println("B grade! 👍");
} else {
    System.out.println("Keep trying! 💪");
}
✏️ Try changing the score!
Click "Run Code" to see the magic! ✨
⚡

Ternary Operator

A super quick way to write if-else in one line! 🚀

int age = 18;
String status = (age >= 18) ? "Adult" : "Minor";
System.out.println(status);
💡

Pro Tip: You can put if statements inside other if statements!

Loops

🔄

For Loop

Repeat code a specific number of times! Perfect for counting! 🔢

for (int i = 1; i <= 5; i++) {
    System.out.println("Count: " + i);
}
✏️ Try it yourself!
Click "Run Code" to see the magic! ✨
⏰

While Loop

Keep repeating while something is true! ♾️

int i = 0;
while (i < 5) {
    System.out.println("Count: " + i);
    i++;
}
🎯

Do-While Loop

Do something first, then check if you should repeat!

int i = 0;
do {
    System.out.println("Count: " + i);
    i++;
} while (i < 5);
💡

Cool Tricks: Use "break" to stop early, "continue" to skip ahead!

Arrays

📚

What are Arrays?

Arrays store multiple items in one variable! Like a shopping list! 🛒

String[] fruits = {"Apple", "Banana", "Orange"};
int[] numbers = {1, 2, 3, 4, 5};
🔢

Accessing Items

Each item has an index (position) starting from 0!

String[] cars = {"Volvo", "BMW", "Ford"};
System.out.println(cars[0]);  // Volvo
System.out.println(cars[1]);  // BMW
System.out.println(cars[2]);  // Ford
🔄

Loop Through Arrays

String[] fruits = {"Apple", "Banana", "Orange"};
for (int i = 0; i < fruits.length; i++) {
    System.out.println(fruits[i]);
}
✏️ Try it yourself!
Click "Run Code" to see the magic! ✨
💡

Remember: Arrays start at 0! The first item is array[0], not array[1]!
